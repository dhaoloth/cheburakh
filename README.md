# Чебурах

Публичный канал распространения подписанных Android APK приложения «Чебурах».

В этом репозитории размещаются **только выпуски приложения** (GitHub Releases): подписанные APK, файлы SHA-256 и краткие примечания к выпуску. Исходный код, подписки, настройки пользователей, диагностические архивы, ключи и токены здесь не публикуются.

**Статус:** канал создан; автоматическая публикация и обновление приложения ещё не подключены. Отсутствие релизов сейчас нормально.

Для обновления установленной версии используются только стабильные выпуски (не draft и не prerelease). При установке Android проверяет подпись APK; обновления должны быть подписаны тем же ключом, что и установленная версия.
